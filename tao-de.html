Tạo đề từ PDF

Về sổ điểm

1 Thông tin đề

Đề sẽ lưu vào thư mục

2 Chọn file PDF

File PDF này cũng là file học sinh bấm "Tải đề" sẽ nhận được, nên đừng để đáp án trong đó.

3 Cắt từng câu, chọn đáp án

Chọn phần ở cột bên phải, rồi kéo chuột khoanh từng câu trên trang PDF theo thứ tự (khoanh cả phương án A, B, C, D). Câu bị ngắt sang trang sau: bấm "Nối vùng" ở câu đó rồi khoanh nốt phần còn lại.

4 Lưu đề

Bấm "Lưu vào thư mục project" rồi chọn thư mục web-luyen-de trên máy. Trang sẽ tạo thư mục đề (ảnh từng câu, file PDF, de.js) và tự thêm đề vào de-thi/danh-sach.js. Sau đó commit và push lên GitHub như bình thường. Nếu Chrome báo không mở được thư mục (thường do thư mục nằm trong iCloud Drive), dùng nút "Tải về file .zip".
